# VOC Taxonomy v0.1

AI VOC Ops에서 사용하는 고객문의 분류 기준입니다.

이 taxonomy의 목적은 LLM이 임의의 라벨을 생성하지 않도록 제한하고, VOC를 동일한 기준으로 집계·비교·평가할 수 있게 만드는 것입니다.

## 1. Major / Subcategory

### 배송

| Subcategory | Definition | Example |
|---|---|---|
| 출고 지연 | 판매자 출고가 예정 시점보다 늦어진 문의 | 아직 발송이 안 됐어요 |
| 배송 지연 | 출고 후 택배 이동 또는 도착이 지연된 문의 | 택배가 며칠째 움직이지 않아요 |
| 배송완료 미수령 | 배송완료 상태지만 실제 상품을 받지 못한 문의 | 배송 완료인데 못 받았어요 |
| 배송 조회 | 송장 또는 현재 배송 상태 확인 | 송장 조회가 안 돼요 |
| 배송지 변경 | 주문 후 배송 주소 변경 요청 | 배송지 바꿀 수 있나요 |
| 배송 중 분실 | 배송 과정에서 상품 분실이 의심되거나 확인된 문의 | 택배가 중간에서 사라진 것 같아요 |

### 주문/결제

| Subcategory | Definition | Example |
|---|---|---|
| 결제 실패 | 카드·간편결제 등 결제 승인 실패 | 카드 결제가 안 됩니다 |
| 중복 결제 | 동일 주문 또는 금액이 두 번 이상 결제 | 두 번 결제됐어요 |
| 주문 변경 | 옵션·수량 등 주문 내용 변경 | 옵션 바꾸고 싶어요 |
| 주문 확인 | 주문 접수 또는 주문 상태 확인 | 주문이 정상 접수됐나요 |
| 쿠폰/프로모션 | 쿠폰·프로모션 조건 또는 적용 실패 | 쿠폰 적용이 안 돼요 |
| 가격/할인 | 판매가·할인가·가격 차이 문의 | 왜 가격이 달라요 |

### 취소/환불

| Subcategory | Definition | Example |
|---|---|---|
| 주문 취소 | 주문 전체 또는 일부 취소 요청 | 주문 취소하고 싶어요 |
| 환불 지연 | 취소·반품 이후 환불 처리가 지연 | 환불이 아직 안 됐어요 |
| 부분 환불 | 전체 결제금액 중 일부만 환불 | 일부만 환불됐어요 |
| 환불 금액 | 환불 금액 산정 또는 차액 문의 | 왜 이 금액만 환불됐나요 |
| 취소 불가 | 취소 제한 또는 실패 이유 문의 | 왜 취소가 안 되나요 |

### 교환/반품

| Subcategory | Definition | Example |
|---|---|---|
| 단순 변심 반품 | 상품 문제 없이 고객 변심으로 반품 | 마음이 바뀌어서 반품하고 싶어요 |
| 상품 불량 | 상품 기능·품질상 하자 | 제품이 작동하지 않아요 |
| 파손 | 상품이 깨지거나 훼손되어 도착 | 깨져서 왔어요 |
| 오배송 상품 | 주문과 다른 상품 또는 옵션 수령 | 다른 상품이 왔어요 |
| 교환 절차 | 교환 신청 방법·절차·진행상태 | 교환은 어떻게 하나요 |
| 반품비 | 반품 배송비 또는 비용 부담 문의 | 반품 배송비가 왜 발생하나요 |

### 상품정보

| Subcategory | Definition | Example |
|---|---|---|
| 사용법 | 상품 사용 방법·순서·주의사항 | 어떻게 사용하나요 |
| 성분/소재 | 원료·성분·재질 문의 | 어떤 성분이 들어있나요 |
| 옵션/사이즈 | 옵션·색상·용량·사이즈 선택 | 어떤 옵션을 골라야 하나요 |
| 재고/재입고 | 품절 여부 또는 재입고 일정 | 언제 재입고되나요 |
| 호환/적합성 | 다른 제품 또는 특정 조건에서의 적합성 | 이 제품과 같이 써도 되나요 |
| 유통기한/보관 | 사용기한·유통기한·보관방법 | 유통기한이 어떻게 되나요 |

### 계정/서비스

| Subcategory | Definition | Example |
|---|---|---|
| 로그인 | 로그인 실패 또는 인증 문제 | 로그인이 안 돼요 |
| 회원정보 | 전화번호·주소·이메일 등 정보 변경 | 전화번호 변경하고 싶어요 |
| 포인트/적립금 | 적립·사용·소멸 관련 문의 | 적립금이 사라졌어요 |
| 알림/메시지 | 앱·문자·이메일 알림 수신 문제 | 알림이 안 와요 |

### 클레임/기타

| Subcategory | Definition | Example |
|---|---|---|
| 반복 불만 | 동일 문제가 여러 차례 문의 후에도 미해결 | 계속 문의했는데 해결이 안 됐어요 |
| 정책 이의 | 회사 정책 또는 처리 기준에 대한 이의 | 왜 이런 정책인가요 |
| 상담 불만 | 상담 응대 품질·태도·처리에 대한 불만 | 상담 대응이 불친절했어요 |
| 개인정보/보안 | 개인정보 노출·오사용·계정 보안 | 제 개인정보가 다른 사람에게 보였어요 |
| 기타 | 현재 taxonomy로 의미 있게 분류하기 어려움 | 분류 기준에 없는 문의 |

## 2. Boundary Rules

겹칠 수 있는 문의는 아래 기준을 우선 적용합니다.

- `오배송 상품`은 상품 자체가 잘못 도착한 경우에만 사용합니다. 배송 위치가 잘못된 문제는 배송 영역에서 처리합니다.
- `배송 중 분실`은 택배 이동 과정에서 분실이 의심되는 경우, `배송완료 미수령`은 시스템상 배송완료인데 실제 수령하지 못한 경우입니다.
- `상품 불량`은 기능·품질상의 하자, `파손`은 물리적으로 깨지거나 훼손된 상태를 의미합니다.
- `환불 지연`은 환불 시점 문제, `환불 금액`은 금액 산정 문제, `부분 환불`은 일부 금액만 환불된 상태를 의미합니다.
- `기타`는 편의상 사용하는 기본값이 아니라 기존 분류로 의미 있게 설명할 수 없을 때만 사용합니다.

## 3. Auxiliary Tags

### Priority

| Value | Definition |
|---|---|
| low | 정보성 문의로 즉시 처리 필요성이 낮음 |
| normal | 일반적인 CS 처리 범위 |
| high | 금전·미수령·중복결제·반복 불만 등 빠른 확인 필요 |
| critical | 개인정보·보안 또는 즉각적인 리스크 대응 필요 |

### Sentiment

- `positive`
- `neutral`
- `negative`

Sentiment는 고객의 감정 상태를 보조적으로 집계하기 위한 태그이며, VOC category를 결정하는 기준으로 사용하지 않습니다.

### Human Review

다음 조건에서는 `requires_human_review = true`를 우선합니다.

- priority가 `high` 또는 `critical`
- 개인정보/보안 관련 문의
- 중복 결제, 배송완료 미수령, 반복 불만 등 후속 판단이 필요한 문의
- AI 분류 확신도가 낮거나 `기타`로 분류되는 경우

## 4. Evaluation Policy

Taxonomy는 고정된 정답이 아니라 평가 결과를 통해 개선합니다.

1. 사람이 gold label을 생성합니다.
2. AI prediction과 비교합니다.
3. 반복되는 오분류 유형을 확인합니다.
4. label 정의 또는 boundary rule을 수정합니다.
5. 동일한 gold dataset으로 다시 평가합니다.

변경 시 `docs/decisions.md`에 변경 이유를 기록합니다.
