# VOC Taxonomy

Initial taxonomy draft.

| Major category | Example subcategories |
|---|---|
| 배송 | 출고 지연, 배송 지연, 배송완료 미수령, 주소 변경 |

| 취소/환불 | 주문 취소, 환불 지연, 부분 환불 |
| 교환/반품 | 단순 변심, 오배송, 파손/불량 |
| 상품정보 | 성분, 사용법, 옵션, 재고 |
| 클레임 | 반복 불만, 강성 문의, 정책 이의 |
| 기타 | 분류 불가 |
